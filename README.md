# Cuaderno de notas — Edición Comunitaria

Aplicación web progresiva (PWA) para redactar artículos, apuntes y reflexiones. Se puede utilizar directamente desde el enlace en un navegador o instalar opcionalmente en una computadora, tableta o teléfono.

## Uso online y offline

- Puedes abrir la aplicación desde el navegador sin instalarla.
- Si lo deseas, puedes instalarla como aplicación desde el botón **Instalar** o desde el menú del navegador.
- Después de cargarla una vez con conexión, los archivos de la aplicación quedan disponibles para trabajar sin conexión, siempre que el navegador conserve sus datos y el almacenamiento del sitio.
- Las notas se guardan localmente en el dispositivo. No hay cuentas, inicio de sesión, Supabase ni biblioteca en la nube.

## Biblioteca local en una carpeta

En navegadores compatibles, principalmente Chrome y Edge en computadoras, abre **Biblioteca** y selecciona **Elegir carpeta local**. La aplicación guardará allí un archivo llamado `Biblioteca-Cuaderno-de-Notas.json` y lo actualizará al guardar, importar o eliminar apuntes.

El navegador puede pedir permiso para volver a acceder a la carpeta. En dispositivos o navegadores que no permitan seleccionar carpetas, la biblioteca seguirá funcionando en el almacenamiento local del navegador.

La carpeta elegida está vinculada al perfil del navegador y al dispositivo. Para usar los apuntes en otro dispositivo, exporta un respaldo y luego impórtalo allí.

## Respaldos

En **Biblioteca** puedes exportar, compartir o importar un respaldo JSON. No hay sincronización automática entre dispositivos.

Exporta copias periódicamente. Si se borran los datos del navegador, se pierde el dispositivo o se elimina el archivo de la carpeta, los apuntes podrían perderse.

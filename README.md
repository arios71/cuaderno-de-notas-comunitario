# Cuaderno de notas — Edición Comunitaria

PWA para apuntes de mensajes, artículos y reflexiones. No utiliza cuentas ni bibliotecas en línea; guarda los datos localmente.

En **Biblioteca** puedes exportar, compartir o importar un respaldo JSON. No hay sincronización automática entre dispositivos: exporta en uno e importa en el otro.

Exporta copias periódicamente. Si se borran los datos del navegador o se pierde el dispositivo, los apuntes locales podrían perderse.
